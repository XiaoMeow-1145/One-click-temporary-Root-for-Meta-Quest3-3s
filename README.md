# One-click-temporary-Root-for-Meta-Quest3-3s

One-click temporary Root for Meta Quest3/3s This tool is designed to take advantage of the vulnerability CVE-2026-43499; it helps you obtain root privileges associated with this vulnerability, allowing you to gain temporary root access on your device adapted from IonStack (CVE-2026-43499) in [CyberMeowfia](https://github.com/NebuSec/CyberMeowfia).

# Ideas？
I want to create a one-click tool for this project, so as to avoid all the hassle; it should be accessible to everyone and easy to use, requiring no need to enter commands – everything can be done with just one click
